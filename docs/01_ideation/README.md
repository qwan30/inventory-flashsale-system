# Ideation Notes

Use this folder for early-stage problem framing before a concrete implementation plan exists.

Good content:

- problem statements
- constraints and assumptions
- option comparisons
- tradeoff notes
- open questions that still affect direction

Keep notes short and decision-oriented. When an idea becomes actionable, move the plan into `docs/02_planning/`.
