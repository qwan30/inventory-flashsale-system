# 2026-03-21 GitNexus Project Integration

## Scope Delivered

This slice integrated GitNexus into the repository as project-local developer tooling so future Codex and Claude-style sessions can query a prebuilt code graph instead of relying only on file search.

Delivered in repo:

- project-local GitNexus MCP wiring in `.codex/config.toml`
- repo-scoped `.gitnexusignore` to keep indexing focused on the actual application workspace
- initial GitNexus index generation for the current commit
- GitNexus context appended to `AGENTS.md`
- repo-local `CLAUDE.md` for Claude-style clients
- repo-local `.claude/skills/gitnexus/` skill bundle generated by GitNexus
- `.gitignore` updated to ignore `.gitnexus`

## Integration Details

- `.codex/config.toml` now registers a `gitnexus` MCP server using the Windows-safe command form:
  - `cmd /c npx -y gitnexus@latest mcp`
- `.gitnexusignore` excludes non-build or agent-workspace directories from the graph:
  - `.codex/`
  - `everything-claude-code/`
  - `skills/`
  - `history/`
  - build artifacts and local caches
- The initial index was created from the repo root with:
  - `npx -y gitnexus@latest analyze`
- The generated GitNexus instruction block was normalized to ASCII after generation because the package emitted Windows-encoded punctuation in `AGENTS.md` and `CLAUDE.md`.
