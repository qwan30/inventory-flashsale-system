# History

This folder stores concise dated records of important completed work and important discoveries.
Choose this folder for short cross-session memory, milestone recap, or durable discoveries. Do not use it as the only write-up when a fuller plan, implementation note, or audit belongs in another folder.

Use filename format:

- `YYYY-MM-DD-topic.md`

Entry rules:

- keep entries concise
- record only durable signal
- link to the canonical doc when a fuller write-up exists
- include verification evidence when available

Read the newest relevant entry first when resuming work after a gap.
