# Audit And Remediation Notes

Use this folder for targeted reviews and follow-up work.
Choose this folder when the prompt outcome is mainly audit, investigation, review, or remediation planning.

Good content:

- concurrency or correctness audits
- performance investigations
- failure-mode analysis
- remediation plans
- postmortems

Prefer one file per audit topic with clear findings, risks, and next actions.
Use dated filenames like `YYYY-MM-DD-topic.md`.
