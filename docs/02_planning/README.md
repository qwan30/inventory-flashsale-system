# Planning Notes

Use this folder for actionable plans after ideation and before or alongside implementation.
Choose this folder when the prompt outcome is mainly planning rather than shipped implementation.

Good content:

- roadmaps
- milestone plans
- phased delivery plans
- execution-ready work slices
- durable planning docs that future sessions should be able to reuse

Keep concrete plans in their own files with descriptive names. Do not store a substantive plan only inside this folder `README.md`.
Use dated filenames like `YYYY-MM-DD-topic.md`.
